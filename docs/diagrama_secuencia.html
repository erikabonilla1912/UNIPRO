Diagrama de Secuencia — UNIPRO

Flujo de mensajes entre participantes para los 4 escenarios principales del sistema.

Escenarios cubiertos:
  • Escenario 1 — Inicio de sesion: el usuario envía credenciales, Express verifica contra MongoDB y devuelve un JWT.
  • Escenario 2 — Listar proyectos: Angular consulta la API, el Interceptor agrega el token, Express filtra solo los aprobados.
  • Escenario 3 — Publicar proyecto: el AuthGuard verifica la sesion, Express valida el JWT y guarda en MongoDB.
  • Escenario 4 — Admin aprueba proyecto: Express verifica el rol admin antes de permitir el cambio de estado.

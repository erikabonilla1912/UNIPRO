Actores:
  • Visitante — usuario no autenticado. Puede ver, buscar proyectos y registrarse.
  • Usuario — autenticado. Puede publicar proyectos, descargarlos y gestionar reclamos.
  • Admin — rol especial. Puede aprobar/rechazar proyectos y ver todos los reclamos.
